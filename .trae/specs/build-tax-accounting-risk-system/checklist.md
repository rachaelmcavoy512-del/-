# Checklist

## 纳税人主体管理
- [x] 支持创建多个纳税人主体
- [x] 区分小规模/一般纳税人两种类型
- [x] 按纳税人类型加载对应科目体系
- [x] 主体类型变更不丢失历史凭证与报表

## 凭证记账
- [x] 支持凭证录入并校验借贷平衡
- [x] 支持凭证审核、过账、作废
- [x] 已过账凭证不可直接修改，需红冲
- [x] 支持期末损益结转
- [x] 科目余额实时更新

## 财务报表
- [x] 自动生成资产负债表（资产=负债+所有者权益）
- [x] 自动生成利润表
- [x] 自动生成现金流量表
- [x] 自动生成科目余额表、明细账、总账
- [x] 报表支持月/季/年查询
- [x] 凭证变动后报表数据重算保持一致

## 数据上传与导入
- [x] 支持发票数据导入并去重（进销项归类）
- [x] 支持银行流水导入
- [x] 支持工资表导入
- [x] 导入校验失败行可标注并修正后重导

## 税务申报
- [x] 一般纳税人增值税申报表（主表+附列资料一至五）自动归集
- [x] 小规模纳税人增值税申报表自动生成
- [x] 企业所得税预缴/汇算清缴申报表
- [x] 附加税、个税、印花税申报表
- [x] 申报状态跟踪（草稿/待申报/已申报/已缴款）

## 税务风险监控（核心）
- [x] 内置9类基础风险指标及阈值
- [x] 数据上传/凭证过账后实时触发风险扫描（5秒内）
- [x] 风险事件按高/中/低分级并预警
- [x] 高风险事件推送给管理员
- [x] 支持风险整改任务分配与状态跟踪
- [x] 风险阈值可配置并支持历史数据重扫
- [x] 风险看板展示数量、等级分布、整改率、环比趋势

## 权限与审计
- [x] 角色权限控制（管理员/会计/审计/查询）
- [x] 关键操作审计日志且不可篡改

## 集成验证
- [x] 端到端流程测试通过（凭证→报表→申报→风险预警）
- [x] 9类风险指标命中测试覆盖
